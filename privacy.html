Privacy Policy

BotAss · effective 10 October 2026

Summary

BotAss is a personal assistant used by exactly one person — the owner of the Google Cloud project it belongs to. It works only with that person's own Google account. Nobody else's data is collected.

Google data it accesses

  • Gmail (read; create drafts; send a draft): to answer the owner's questions about his mail and to prepare replies. A message is sent only after the owner confirms that specific message.
  • Google Calendar (read; create and edit events): to answer questions about the owner's schedule and to add events he confirms. BotAss does not delete mail or events.

How the data is processed and stored

  • Processing happens locally, on the owner's own computer.
  • The OAuth refresh token is stored only in a local file on that computer. Access tokens are kept in memory only.
  • BotAss keeps no database of your mail or calendar. Short-lived working data (for example, a pending confirmation for an email draft) is kept locally and removed after use.

Sharing

Google user data is not sold, not shared with or transferred to third parties, not used for advertising, and not used to develop, improve or train generalized AI or machine learning models. When the owner switches the assistant to a cloud-hosted language model, all Gmail and Calendar functions are switched off automatically, so mail and calendar content is not sent to that cloud model.

Limited Use

BotAss's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes BotAss's access on the owner's computer.
